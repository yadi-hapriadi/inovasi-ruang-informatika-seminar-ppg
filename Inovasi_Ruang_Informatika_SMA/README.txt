CARA MULAI DI LOCALHOST
1. Ekstrak seluruh isi ZIP ke satu folder. Jangan memindahkan index.html keluar dari folder assets.
2. Pastikan Python 3 terpasang.
3. Di Windows, klik dua kali mulai_localhost.bat. Alternatif: buka terminal pada folder ini lalu jalankan python start_localhost.py (di Windows dapat memakai py -3 start_localhost.py).
4. Browser akan terbuka ke alamat localhost yang dicetak server, biasanya http://127.0.0.1:8000/.
5. Biarkan jendela server tetap terbuka saat web digunakan; tekan Ctrl+C untuk menghentikannya.

Aplikasi tidak memerlukan npm install atau dependensi JavaScript tambahan. Pertahankan struktur assets agar tautan PDF dan modul berfungsi. Baca README_LOCALHOST.md untuk petunjuk lengkap.

PERTEMUAN 5–8 · PROYEK VIDEO KLIP (PjBL)
- Pertemuan 5: Pemanfaatan Media Sosial, Etika Kreator, Jejak Digital, dan Perencanaan Project. Output: analisis kasus etika/jejak digital, konsep/pesan, storyboard, shot list, pembagian peran, dan timeline.
- Pertemuan 6: Produksi/Shooting Video Clip. Output: footage sesuai storyboard dan shot list, hasil review/retake, serta file yang telah di-backup.
- Pertemuan 7: Editing, Quality Control, dan Upload Video. Output: video final yang telah diedit, dicek mutunya, diekspor, dan dikumpulkan.
- Pertemuan 8: Screening, Presentasi, Feedback, Nominasi/Apresiasi, dan Refleksi. Output: screening, presentasi proses, feedback konstruktif, nominasi, refleksi, dan posttest.

Tema kelompok sesuai modul: Kelompok 1–3 mengembangkan Video Clip Mars SMAN 24 Bandung; Kelompok 4–6 mengembangkan Video Clip “Rukun Sama Teman”.

Sumber guru 42 halaman disertakan di assets/referensi/Modul_Ajar_Pemanfaatan_Media_Sosial_dan_Kreasi_Konten_Digital_PjBL.pdf. Slide presentasi tetap tersedia sebagai materi pendamping di assets/materi/pertemuan-05-08-media-sosial-konten-digital.pdf.

LKPD pada web merupakan panduan proses: pengamatan, pencatatan bukti, perencanaan/produksi, analisis, revisi, diskusi, kesimpulan, dan refleksi. Kuis formatif terpisah dari LKPD. Model dan sintaks ditampilkan pada Ruang Guru; murid melihat tugas dan aktivitas tanpa label “HOTS”.

Pemetaan pedagogis lainnya:
- Pertemuan 2: Problem Based Learning (PBL), menggunakan kasus simulasi keterlambatan masuk kelas dengan data waktu yang jelas.
- Pertemuan 3: eksplorasi terbimbing dan Cooperative Learning untuk Linear Search vs Binary Search.
- Pertemuan 4: Direct Instruction + Cooperative Learning untuk Sorting: demonstrasi, latihan terbimbing, praktik kelompok, presentasi, feedback, evaluasi, refleksi.
- Pertemuan 9–10: demonstrasi eksplisit/praktik terbimbing untuk cover Word serta Heading dan daftar isi otomatis.

Fitur penyimpanan progres dan draf pada versi ini menggunakan browser lokal. Login lintas perangkat dan sinkronisasi kelas memerlukan backend untuk penerapan produksi.

PENILAIAN INTERAKTIF · KUIS, ESAI, DAN UTS
- Di Ruang Guru > Asesmen & Nilai, guru dapat membuat soal pilihan ganda dan esai, menentukan kelas, pertemuan atau UTS, durasi, poin, dan kunci jawaban PG. Asesmen disimpan sebagai draf lalu dapat diterbitkan atau ditutup.
- Di Ruang Murid > Kuis & Ujian, murid mengerjakan satu soal per layar, menavigasi nomor soal, melihat progres, dan menggunakan timer bila disetel. PG dinilai otomatis; esai menunggu penilaian guru.
- Guru dapat meninjau jawaban esai, memasukkan skor dan umpan balik, melihat nilai akhir, serta mengekspor rekap ke CSV.
- Bank asesmen awal mencakup Berpikir Komputasional (kasus simulasi terlambat), Searching, Sorting, Etika dan Mutu Konten Digital, serta contoh UTS Informatika. UTS contoh berisi 8 PG bernilai 5 poin dan 2 esai bernilai 30 poin (total 100).
- Jawaban, draf pengerjaan, skor, dan umpan balik disimpan pada browser/perangkat lokal yang digunakan. Untuk penyimpanan terpusat dan sinkronisasi antarkelas/perangkat dibutuhkan backend.
